# GuiStack frontend

## System requirements

- Node.js v24.x ([Download](https://nodejs.org/en/download))
- pnpm ([Download](https://pnpm.io/installation))

## Installing dependencies

```sh
pnpm install
```

## Running the project

### Local development

```sh
pnpm run dev --open
```

## Building the project

```sh
pnpm run build
```
